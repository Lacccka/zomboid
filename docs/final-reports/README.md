# Final reports

This directory stores final reports for compatibility issues that have been reproduced, fixed and confirmed in-game.

Use one Markdown file per closed issue or issue group. A final report should record:

- affected Project Zomboid build and patch versions;
- symptoms and confirmed root cause;
- files and components changed;
- final implementation approach;
- validation result and closure status;
- any important constraints that should not be regressed later.

Reports here describe the confirmed end state. Intermediate hypotheses and discarded approaches should only be mentioned when they are useful for preventing the same regression.
