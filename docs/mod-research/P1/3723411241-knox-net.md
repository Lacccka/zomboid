## Вердикт

Фокус: persistent group messaging, membership/admin roles, unread state and file persistence.

Useful for group snapshot projections, targeted broadcasts and offline member persistence.

## Архитектура

| Слой | Что находится в слое |
|---|---|
| CLIENT | ChatUI requests lists/history/messages/group actions and renders notifications/unread state. |
| SERVER | validates membership, group limits, users, rate limits and writes conversation metadata/history/indexes. |
| SHARED | Shared defines normalized usernames, group actions, IDs, limits and public summaries. |

## Network

- request/result command protocol
- targeted notifications to online members
- SP direct receive fallback

Вывод по authority: серверный слой присутствует, но доверие проверяется по каждому handler отдельно.

## Persistence и identity

ChatPersistence stores known users, per-user index, conversation meta and message history in files.

## Полезные механики

- server-owned group roster
- offline durable messages
- per-member projection/unread
- owner/admin actions
- targeted fan-out

## Риски и anti-patterns

- group creation directly lists members rather than an invitation handshake
- file count/history growth needs limits
- B41 label requires 42.20 test
