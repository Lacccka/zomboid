## Вердикт

Фокус: generic synchronization and framework services.

Study the dispatcher and callback correlation, but prefer a smaller command whitelist in LaccckaQuestFramework.

## Архитектура

| Слой | Что находится в слое |
|---|---|
| CLIENT | SyncClient routes registered calls and receives updates/alerts; UI-facing modules consume the callbacks. |
| SERVER | SyncServer dispatches modules to QSystem, NFO, PrivateSync and Marketplace handlers. |
| SHARED | registries, utility helpers and protocol-neutral data live under common/shared. |

## Network

- sendClientCommand/sendServerCommand
- Events.OnClientCommand/OnServerCommand
- generic envelope {sender,args,entry.id}

Вывод по authority: серверный слой присутствует, но доверие проверяется по каждому handler отдельно.

## Persistence и identity

Core delegates persistence to consumers; SSR Quest owns player quest saves.
