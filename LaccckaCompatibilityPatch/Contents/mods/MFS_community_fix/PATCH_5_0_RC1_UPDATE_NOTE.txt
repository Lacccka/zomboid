-------------------------------------------------------------------------------
 WHAT RC1 FIXES  (two things, both verified in a live MP session)
-------------------------------------------------------------------------------

1. THE ATTACHMENT POSITION WRENCH THREW AN ERROR ON EVERY CLICK.
   Clicking a part in the position editor produced a red error and the sliders
   never bound to anything, so nothing could be moved.

   Cause: the code read a private field by Java reflection
   (getNumClassFields / getClassField / getClassFieldVal). Those are DEBUG-ONLY
   in B42.20 - the engine refuses them outside debug mode. Replaced with the
   public getter item:getWorldStaticModel(), already used in five other places
   in this mod.

   THIS IS AN UPSTREAM BUG. It affects the original Modern Firearms System too,
   for every player not running the game in debug mode.

2. HELD RIFLE DREW IN THE WRONG POSE AFTER ATTACHING A PART (MULTIPLAYER).
   The character dropped to the standing stance and the rifle rendered rotated,
   with the forward hand at the optic instead of the grip.

   Cause: the weapon was left in the PRIMARY hand with the OFF-HAND EMPTY. A
   two-handed weapon is held by putting the same item in BOTH hands. Attaching
   a part queues ISUpgradeWeapon then ISEquipWeaponAction; in MP the part is
   already attached by the time the queue is checked, so the first action
   rejects itself as redundant and the queue is discarded - taking the equip
   action, and the two-handed grip, with it.

   Fixed by MFSTwoHandGripFix.lua, which restores the grip when a two-handed
   weapon is left with an empty off-hand.

   Single player never showed this. Found only by logging a real MP session.

   ALSO FIXED ALONG THE WAY: MFSPartOffsetPersistence was rebuilding the
   equipped weapon model on EVERY FRAME while a position slider was dragged
   (~20 consecutive frames, 91 times in one short session). Part changes and
   offset changes are now tracked separately; offsets still apply every frame,
   but the expensive rebuild is limited to ~12 per second.
