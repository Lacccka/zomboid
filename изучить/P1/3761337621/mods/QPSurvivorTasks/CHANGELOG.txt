v0.6.1
- Added an admin-controlled Public Task Creation mode for administrator-created boards
- Any player can add standard preset or custom tasks while Public Task Creation is enabled
- Public contributors can complete tasks but cannot remove tasks, clear the board, remove the board, or change public mode
- Public contributors cannot create Reputation reward tasks
- Existing safehouse boards remain unchanged
- Existing administrator boards remain locked by default
- Existing tasks and board data remain compatible
- Added English, French, Russian, Simplified Chinese, Brazilian Portuguese, and Spanish translations
- Applied to Build 41 and Build 42
