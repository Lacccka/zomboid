QP Survivor Tasks - Multiplayer Base Board
========================================

QP Survivor Tasks adds a lightweight multiplayer task board system for Project Zomboid Build 42.

Players can turn valid base objects into task boards, add quick preset tasks or custom survivor tasks, mark tasks as done, remove individual tasks, and keep long-term co-op groups organized directly in-game.

Built for:
- Long-term multiplayer servers
- Co-op bases
- Roleplay communities
- Survivor groups
- Dedicated servers

Features:
- Create task boards on valid objects
- Add custom tasks
- Add 6 quick preset tasks
- Mark tasks as done
- Remove individual tasks
- Clear task boards
- Remove task boards
- Shows who created tasks
- Shows how long ago tasks were added
- Persistent object-based storage
- Proper task board UI window
- Clean right-click submenu
- Build 42 ready
- Multiplayer/server friendly design

Quick Presets:
- Need fuel
- Need food
- Need medicine
- Repair generator
- Clear zombies nearby
- Area not safe
